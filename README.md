# Embedded Systems World

A practical learning hub for embedded firmware engineers.

This repository hosts the Embedded Systems World website and technical learning content focused on:

- Embedded C and C++
- ARM Cortex-M fundamentals
- Interrupts and exception handling
- RTOS concepts
- Firmware debugging
- Low-level peripherals and protocols
- Interview preparation
- Production-style embedded examples

## Website

The site is designed to be published with GitHub Pages from this repository.

## Content philosophy

Explain low-level embedded concepts visually, practically, and from first principles — with enough depth to be useful to working firmware engineers.
